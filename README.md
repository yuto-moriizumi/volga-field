# Volga Field

ゴッドフィールド風のターン制カードバトルRPG。

## 構成

- `apps/web` - Next.js 15 (App Router) のフロントエンド
- `apps/server` - WebSocket 対戦サーバー (Node.js + ws)
- `packages/game-core` - 純粋なゲームロジック (カード/戦闘/デッキ)
- `packages/shared` - 共通型とプロトコル定義

## 開発

```bash
npm install
npm run build:shared
npm run build:core
npm run dev
```

- Web: http://localhost:3000
- Server: ws://localhost:4000

## 身内ネタの追加方法

`packages/game-core/src/cards.ts` の `BASE_CARDS` 配列にカードを追加するだけで
新しいカードを作成できる。各カードに `customTags: ['meme', ...]` を付けると
フィルタリングできる。

## ゲームルール

- HP20で開始。**HPに上限はなく**、回復によって20を超えることができる
- MP10で開始（MPは上限あり）
- 手札5枚、山札から自動補充
- デッキは全99枚のカードから30枚を選んで構成する
- ターン制: 1ターン中に複数のカードをプレイでき、好きなタイミングで「ターン終了」を宣言する
- カテゴリ: 武器 / 盾 / 薬 / 奇跡 / 特殊 / 取引 / 無属性 / 雑貨 / 政党
- 修行モード: 2〜9人でプレイ可能。終末の時は G.F.50 / G.F.75 / G.F.100 から選択できる（なしも可）

### 政党（守護神）

政党カードを使うと政党に所属する。所属した状態で他のプレイヤーのターンが終わるたび、
終了したプレイヤー以外の生存している政党所属者がそれぞれ **25%** で政党行動を起こす。
行動は政党ごとの重み付き抽選で決まり、攻撃対象は行動者から見た生存中の相手からランダムに選ばれる。

| 政党 | 政党行動 (重み) |
| --- | --- |
| 共産党 | 労働者の反撃: ランダムな相手に3ダメージ (60) / 団結: 自分MP+2 (40) |
| 自民党 | 経済成長: 自分お金+3 (60) / 市場の一撃: ランダムな相手に2ダメージ (40) |
| 民主党 | 世論の追い風: 自分MP+2 (50) / 政策協力: 自分HP+2 (50) |
| 立憲帝政党 | 王権の威光: ランダムな相手に3ダメージ (50) / 城塞の守り: 自分HP+3 (50) |
| 緑の党 | 自然の恵み: 自分HP+3 (60) / 再生エネルギー: 自分MP+2 (40) |
| 無政府党 | 直接行動: ランダムな相手に2ダメージ (55) / 略奪: お金を持つ相手から2円奪う (45) |

- HP回復に上限はなく、MP回復は最大MPまで
- 略奪は所持金のある生存相手がいない場合は何も起こらない
- 政党行動で手番プレイヤーが倒れた場合、勝敗が決していなければ次の生存者へ手番が移る

### 終末の時と悪魔

終末の時が有効な間、手札を補充するために1枚引くたびに **25%** で悪魔が出現する。
出現する悪魔は重み付き抽選（合計25）で決まり、手番プレイヤーに効果を与えてゲームを終局へ導く。

| 悪魔 | 行動 | 効果 (重み) |
| --- | --- | --- |
| 🇺🇸 トランプ大統領 | ツイート砲 | 10ダメージ (7) |
| 🐻 プーチン大統領 | 特別軍事作戦 | 20ダメージ (5) |
| 🚀 金正恩委員長 | ミサイル発射 | 30ダメージ (3) |
| 🐦 イーロン・マスク | アカウント凍結 | 神器を2枚捨てる (5) |
| 🏦 日銀総裁 | 金融緩和 | HP+10 (5) |

- 悪魔の効果は手番プレイヤーにのみ作用する
- HP回復に上限はなく、金融緩和でHP20を超えることもある
- 手札が2枚未満でもアカウント凍結は残りの枚数だけ捨てて処理を続ける

実装済みカードの定義は `packages/game-core/src/cards.ts` を正とする。
