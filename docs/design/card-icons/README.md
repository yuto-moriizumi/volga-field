# カードアイコン スタイル試作（階級闘争）

カードは現在すべて絵文字 1 文字（`CardDefinition.emoji`）で表現されている。
不満は「枚数」ではなく**記号のスタイルが弱い**こと。例として `階級闘争 = ✊` は
「手を挙げている人」に見えてしまい、階級闘争の記号性が出ていない。

このディレクトリは、同じモチーフ（突き上げる拳）を 4 つのグラフィック表現で描き、
**実寸 48px で読めるか**を比較するための試作。**アプリへの組み込みは未実施**。

- プレビュー: [`../card-icon-candidates.html`](../card-icon-candidates.html)（サーバー不要・インライン SVG）
- 候補 SVG: [`candidates/`](candidates/)
- 属性色サンプル: [`variants/`](variants/)

## 共通仕様

| 項目 | 値 |
| --- | --- |
| viewBox | `0 0 64 64`（正方形・1:1） |
| 実際の表示 | 手札カード 48px / 詳細カード 48px / 攻撃演出 48px / 図鑑タイル 32px / 図鑑アイコン枠 28px |
| 色数 | 各案 3 色まで |
| 制約 | 文字なし・ハンマーと鎌なし・実在政党ロゴ／政治家の似顔絵なし |
| 生成方法 | SVG を手書き（ラスタ・生成画像なし） |

### 拳の造形メモ

48px で「突き上げる拳」と読ませるために、次の 3 点だけを情報として残している。

1. **拳頭の 4 つの山** — 指が折り込まれていることを示す唯一の手がかり。深さは 2.5〜3 単位
   （48px で約 2px）。深くしすぎると「王冠」、浅すぎると「ミトン」になる。
2. **親指の合わせ目** — 左下から右上へ上がる斜めの 1 本線。ここが水平だと「手を振る人」に、
   ループで閉じると「耳」に見える。拳の左端から 3 単位ほど張り出させて親指の塊を作る。
3. **手首のくびれ** — 拳の幅の約 50%。拳と前腕の境目をはっきりさせるとグローブ感が消える。

拳頭を丸くしすぎるとボクシンググローブ、指の線を増やすと「櫛」に見えるため、
線は最小限（合わせ目＋袖口のみ）にしている。

## 4 案

### A. アジプロ・ポスター — `candidates/a-agip-poster.svg`

赤地に黒ベタの拳、生成りの内枠。印刷物のベタ塗りで、遠目にも形が残る一番素直な政治ポスター。
袖口の 1 本線で「まくり上げた袖」を示している。

- 色: `#c22a21` / `#191310` / `#f4ecd6`
- 48px: **◎** シルエットが最も強く、拳と即断できる。指の刻みは消えるが問題ない。
  内枠 2.6 単位（約 2px）は 48px でも残り、カード内で「印刷物」の印象を作れる。

### B. 構成主義 — `candidates/b-constructivism.svg`

黒地・赤い円・生成りの拳という**反転構成**。ロトチェンコ風に面を分割し、
左上に生成りの斜めの角を落としている。色数は A と同じなのに印象が最も変わる案。

- 色: `#c22a21` / `#191310` / `#f4ecd6`
- 48px: **○** 拳は読めるが、赤い円が大きいため「赤い玉の上の拳」に見え、情報量がやや多い。
  カード内では A より視線を引くので、レアリティの差に使える可能性がある。

### C. ステンシル／スクリーンプリント — `candidates/c-stencil.svg`

生成り地に黒 1 色＋赤い円。`feTurbulence` + `feDisplacementMap`（scale 0.65）で
版ズレ・インクのムラを軽く出し、生成りの微小な抜けを数点置いている。

- 色: `#efe6cd` / `#1b1613` / `#cf3b2c`
- 48px: **○** 輪郭のかすれが効いて質感が出る。ただし腕の下側が少し溶けるので、
  本番で使うならフィルタはさらに弱めるか、48px 以下ではフィルタを切るほうが安全。
  フィルタは SVG 内で完結するため外部依存はない。

### D. 洗練ピクトグラム — `candidates/d-pictogram.svg`

枠なし・生成り地に黒ベタ＋細い抜き線、赤は袖口の 1 点だけ。現行路線の延長で、
他案と比較するための基準案。線画（輪郭のみ）も試作したが、48px では輪郭が
「鍵」や「フック」に見えたため、ベタ＋抜き線に変更した。

- 色: `#f7f2e3` / `#1b1613` / `#d0452f`
- 48px: **○** 読めるが、A と並べると違いが「枠と赤面の有無」だけになりやすい。
  地味さは狙いどおり（比較基準）だが、単体で選ぶと弱い。

## 属性色バリエーション（スタイル A）

`variants/` に 3 枚。**背景色を差し替えるだけでは済まない**組み合わせがあるため、
拳・抜き線・縁の色もセットで定義している。

| 属性 | 地 | 拳 | 抜き線 | 縁 |
| --- | --- | --- | --- | --- |
| 社会主義 | `#c22a21` 赤 | `#191310` 黒 | `#f4ecd6` | `#f4ecd6` |
| 資本主義 | `#22406e` 紺 | `#d9a94a` 金 | `#22406e`（地色で抜く） | `#f4ecd6` |
| 無政府主義 | `#16110f` 黒 | `#f4ecd6` 生成り | `#16110f`（地色で抜く） | `#c9352a` 赤 |

ゲーム既存パレット（teal `#2f7568` / gold `#a17a1f` / 生成り `#f3f6d4`）とは
彩度を合わせすぎず、ポスターとして成立する範囲で振っている。
真鍮寄りの gold `#d9a94a` は紺地で 48px でもコントラストが足りる。

## 実装に進む場合の作業メモ

1. **`CardArt` への集約** — `emoji` の描画は 5 ファイルに散っている。
   `CardView.tsx`（手札 48px）/ `LargeCard.tsx`（詳細 48px）/ `NameList.tsx`（対象政党一覧）/
   `BattleEffects.tsx`（攻撃演出 48px）/ `TextBook.tsx`（タイル 32px・災厄枠 28px、計 5 箇所）。
   `apps/web/src/app/textbook/data.ts` も `card.emoji` を写しているので、
   `CardDefinition` に `art?: string`（アイコン ID）を足し、`<CardArt id size />` に一本化するのが先。
2. **サイズが 48px ではない** — 図鑑タイルは 32px、災厄枠は 28px。今回の 4 案は 48px 基準なので、
   32px では抜き線（2.0〜2.4 単位 ≒ 1.2px）が飛ぶ可能性がある。
   実装時は 32px 用に抜き線を太くした簡易版を出すか、`currentColor` の 2 階調に落とす判断が要る。
3. **枚数** — `cards.ts` に 96、`devils.ts` に 6、`armors.ts` に 1 の `emoji` がある。
   1 枚 1.3〜1.8KB のインライン SVG を 100 枚超そのまま積むとバンドルが膨らむので、
   `<symbol>` のスプライト 1 枚（ID 参照）にするか、`/public` の静的 SVG ＋ `<use>` を推奨。
4. **絵文字のフォールバック** — 未作成カードのために `art` 未定義時は `emoji` を出す
   フォールバックを `CardArt` 内に残すと、段階的に差し替えられる。
5. **色の持ち方** — 属性色はカードの `customTags`（`socialism` など）から決まるので、
   アイコン側に色を焼き込まず CSS 変数（`--icon-field` / `--icon-ink` / `--icon-accent`）で
   受けるほうが、属性追加時に SVG を増やさずに済む。
