# 構想・未実装のゲームデザイン

このファイルは、ゲーム内教典から外した**構想段階・未実装**の内容を保管するためのもの。
実装済みのカード・悪魔・政党・ルールは `packages/game-core` が正であり、
教典は `BASE_CARDS` / `DOOMSDAY_DEVILS` / `PARTY_ACTIONS` から自動生成される。

ここに書かれている内容は、現時点のゲームには反映されていない。
実装する場合は、先に `packages/game-core` のデータとルールを更新し、
その結果として教典へ表示されるようにする。

## 属性と防御

旧教典では、以下の属性と相性ルールを構想していた。
現在の教典では属性を表示せず、属性による防御判定も実装していない。
（一時期は属性を政党イデオロギーに読み替えて表示していたが、これも構想段階の表現。）

- 無属性の攻撃は、どの属性でも防御できる。
- 火属性の攻撃は、水属性で防御できる。
- 水属性の攻撃は、火属性で防御できる。
- 木属性の攻撃は、土属性で防御できる。
- 土属性の攻撃は、木属性で防御できる。
- 光属性の攻撃は、どの属性でも防御できない。
- 闇属性の攻撃は、どの属性でも防御できる。ただし、ダメージを受けると HP0 になる。

属性の種類: 無属性 / 火属性 / 水属性 / 木属性 / 土属性 / 光属性 / 闇属性。

## 災い

戦況が悪化すると「災い」が発生する構想。
災いは全プレイヤーに等しく降りかかる。病は毎ターン 5% の確率で自然に悪化し、
病に病を重ねると悪化する。霧の中から敵に神器を使う場合、使用先は霧の中から無作為に選ばれる。

| 災い | 効果 | 備考 |
| --- | --- | --- |
| 🤧 風邪 | 毎ターン1ダメージ | 悪化すると熱病 |
| 🔥 熱病 | 毎ターン2ダメージ | 悪化すると地獄病 |
| 🌋 地獄病 | 毎ターン5ダメージ | 悪化すると天国病 |
| 🌈 天国病 | 毎ターンHP+5 | 悪化するとHP0になる |
| 🌫️ 霧 | 周りの状況がわからなくなる | |
| ⚡ 閃光 | 防御のときに神器を一つしか使えない | |
| 💫 夢 | 授かった神器が50%の確率で別の神器に見える | |
| ☁️ 暗雲 | 全体攻撃を受けると必ず命中する | |

## 超常現象

神々の気まぐれで世界法則が捻じ曲げられる、稀な現象の構想。

| 超常現象 | 効果 |
| --- | --- |
| 🌒 日蝕 | 無政府主義の攻撃力2倍 |
| ☄️ 流星群 | 全員-3 |
| 🌀 次元断裂 | 神器が一時的に使用不能 |

## 負荷の連携

複数の神器を組み合わせたときの属性ルールの構想。

- 異なる属性の神器を一緒に使うと無属性になる。
- 光属性は、火・水・木・土の代わりになれる。

## 旧・汎用悪魔

政党をモチーフにした現在の終末の悪魔に置き換わる前の、汎用悪魔の構想。
現在の `DOOMSDAY_DEVILS` には含まれていない。

| 悪魔 | 効果 |
| --- | --- |
| 😈 ベリアル | HP半分と引き換えに、強力な神器を得る |
| 👿 アスタロト | 神器を捧げて相手神器を1つ破壊 |
| 🐉 リヴァイアサン | HP3と引き換えに、相手-8 |

## 守護神（政党に置換）

旧教典には「守護神」カテゴリがあり、預言者に常時加護を与える存在として
ミカエルなどの守護神を構想していた。
現在は政党カードと政党行動（`PARTY_ACTIONS`）に置き換わっている。

## 授かり率について

旧教典には「授かり率 3/500」のような数値が表示されていたが、
実装に対応する抽選率は存在しないため削除した。
現在のデッキは全カードから30枚を選んで構成し、カードごとの出現率は設定していない。
